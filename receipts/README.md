# Sample receipts

`demo-prepared.*` is a **prepared** TAP/Ordinals payload sample (not inscribed).
After you inscribe on Bitcoin, store `inscription_id` / `txid` beside the memory.

The same five-field memory and digest are the runnable show-and-tell in [`../examples/demo-memory.json`](../examples/demo-memory.json) and [`../examples/expected-digest.json`](../examples/expected-digest.json). Run `node examples/run-demo.mjs` from the repo root after `npm ci`.
